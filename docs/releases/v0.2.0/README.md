# v0.2.0 release images

- `chatgpt-writer-result.png`: a real ChatGPT connector run saved 10 drafts into 28 available slots. It reported 0 flagged and 0 refused, with a shared-budget change of about $0.0664. Eighteen slots remained empty.
- `buffer-drafts.png`: Buffer showing the same ten drafts, Queue 0 and Sent 0.

These images document the earlier day-2 demo. They are not a new writer run after the feed-freshness fix, and the draft text is not an editorial recommendation. No draft was approved or published in that demo.

Both are 3840×2160 exports enlarged from Retina screenshots. Browser URLs and app content are retained. Tabs, debugging banners, cursor and unrelated extension/profile controls are excluded or cleaned up. The displayed product results were not generated or rewritten. PNG files contain only IHDR, IDAT and IEND chunks, with no ancillary metadata.
